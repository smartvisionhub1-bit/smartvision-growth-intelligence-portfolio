# Security and Confidentiality

This repository is a documentation-only public portfolio.

## Information intentionally excluded

- Passwords and authentication codes
- API keys and OAuth client secrets
- Webhook secrets
- Access and refresh tokens
- Database credentials and private connection strings
- Customer, order, and store data
- Complete production source code
- Private deployment configuration

## Responsible disclosure

If you identify a security concern related to this public documentation, do not publish credentials, tokens, or exploit details in a public issue. Contact the repository owner privately through the GitHub account.
